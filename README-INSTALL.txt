秒登 MiaoDeng - Chrome 插件安装说明
========================================

📦 推荐安装方式：ZIP 安装

安装步骤：

1. 解压此 ZIP 文件到任意位置
2. 打开 Chrome 浏览器
3. 地址栏输入：chrome://extensions/
4. 开启右上角的“开发者模式”开关
5. 点击“加载已解压的扩展程序”
6. 选择解压后的 “chrome-extension” 文件夹
7. 安装完成！✅

⚙️ 配置：

1. 点击浏览器右上角的 ⚡ 图标
2. 点击 ⚙️ 打开设置
3. 填写秒登服务地址（询问管理员）
4. 点击“保存”
5. 设置你的用户名

❓ 常见问题：

Q: 每次打开 Chrome 提示“禁用开发者模式扩展”？
A: 点击“保留”即可，这是 Chrome 的安全提醒。

Q: 无法自动填充？
A: 检查服务器地址和用户名是否正确。

Q: 服务地址应该填什么？
A: 一般填写你的秒登门户地址，例如 http://你的电脑IP:6680。
